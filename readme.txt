Mobile app page shell, PWA install, notifications, and CEM-backed attendee notes for Convention Event Manager.

== Description ==

Optional add-on to Convention Event Manager. Provides the attendee `/app` experience: tabbed mobile page, add-to-home-screen / PWA support, OneSignal notifications, and attendee notes sourced from CEM registrations.

== Installation ==

1. Activate Convention Event Manager first.
2. Activate CEM Mobile App.
3. In CEM → Settings → Mobile App, choose the schedule and confirm the page slug (default `app`).
4. Deactivate the legacy Mobile App Page Shell and SEPA Attendee Notes plugins when you are ready.
